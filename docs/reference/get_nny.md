# get_nny find the nearest year with a computed flight curve

get_nny find the nearest year with a computed flight curve

## Usage

``` r
get_nny(x, y)
```

## Arguments

- x:

  integer Year for which to find the nearest flight curve.

- y:

  vector Years with available flight curve.

## Value

z integer The value of the nearest year with flight curve.
