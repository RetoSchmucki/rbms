# initiate_project Build the folder structure for a generic research project

initiate_project Build the folder structure for a generic research
project

## Usage

``` r
initiate_project(project_name, project_home = NULL)
```

## Arguments

- project_name:

  Name of the project to be used for the parent folder

- project_home:

  Path where the project folder structure to be built, default is the
  current working directory
