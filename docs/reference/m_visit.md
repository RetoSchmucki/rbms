# Toy data set with the date when the sites have been visited for monitoring

Toy data set with the date when the sites have been visited for
monitoring

## Usage

``` r
m_visit
```

## Format

data.table object with visit date long format

- SITE_ID:

  number used as site id, the can be and integer or a string

- DATE:

  date when the observation/count was recorded, format YEAR-MM-DD
